# Slopify

No ads. No subscriptions. Just slop.

## Roadmap

Минималистичный интерфейс клиента помогает ориентироваться, управлять воспроизведением и выполнять текущую задачу.

- [ ] При замене обложки обновлять отдельный файл и теги всех треков альбома.

### Хранение треков на сервере

- Хранить треки в MP3. Альбомы, синглы и EP в серверной модели имеют один тип «альбом».
- При загрузке заполнить год релиза и номер трека до сохранения, если их нет в источнике.
- Записывать метаданные и обложку альбома в теги ID3v2.3 каждого трека.
- Хранить и отдавать обложку отдельным файлом для быстрой загрузки в клиенте.

```text
Исполнитель/
└── [год] Название релиза/
    └── [номер-в-альбоме] Название трека.mp3
```
